## TCP client/server exercise

- Created a local TCP server and client using Python's `socket` module.
- The server and client were configured to use `127.0.0.1`.
- Port `5000` was unavailable because it was already occupied by macOS `ControlCenter`.
- The exercise was moved to port `5001`.
- The server and client were stopped after the exercise.
- Final verification showed that no exercise process was running and port `5001` was not listening.
